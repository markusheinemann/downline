# Downline

A delay rarely stays where it started. Downline reconstructs each aircraft's day from open ADS-B data as a connected 
chain of flights and measures the reactionary delay along it.

> [!Note]
> **Disclaimer on AI usage**
> The code of this project is written by humans. Not because I think it's better, but because I've recently lost my 
> enjoyment of programming due to heavy AI use, and here I want to use my own brain to solve problems.
